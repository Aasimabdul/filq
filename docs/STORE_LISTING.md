## App name
Fliq — File Converter

## Short description
Lightweight offline file converter with batch images, PDF tools and file renaming.

## Full description
Fliq is a lightweight, open-source file converter for Android. Select a file—or select multiple files at once—share it to Fliq, and choose an output format supported by the selected files.

FEATURES
- Convert supported JPG/JPEG, PNG, WebP, BMP, GIF, HEIC and SVG images to JPG, PNG, WebP, BMP or PDF.
- Convert PDF pages to PNG, JPG or WebP.
- Merge multiple selected images into one PDF.
- Extract selectable PDF text into a DOCX Word document.
- Convert DOCX Word and PPTX PowerPoint files to PDF using lightweight, on-device text extraction.
- Batch-convert multiple selected files to one common output format.
- Rename files with Clean, snake_case, Date + name, or a custom name.
- Keep the original file unchanged; save a new output copy.
- Open-source code under GPL-3.0.

PRIVACY
Supported local conversions run on your Android device. Legacy Office and spreadsheet conversions require a separately configured conversion server; files sent to that server leave the device.

IMPORTANT LIMITATIONS
PDF-to-Word only extracts selectable text. Scanned PDFs need OCR, which is not included. DOCX/PPTX-to-PDF conversions are text-first and may not preserve the original layout, images, tables, charts, fonts or animations. File-format support can vary by Android version and file.

Minimum Android version: Android 10 (API 29).

Source code, documentation, releases and issue reporting: https://github.com/Aasimabdul/filq
