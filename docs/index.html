Meet Fliq.

A lightweight, open-source file converter for Android. Convert supported images and documents, batch-convert multiple files to one format, merge images into a PDF, and rename files without changing the originals.

View source on GitHub Releases and APKs Full documentation

Minimum Android version: Android 10 (API 29). Built with low-memory devices in mind.

Image conversion

Convert supported JPG/JPEG, PNG, WebP, BMP, GIF, HEIC and SVG files to JPG, PNG, WebP, BMP or PDF. Decoder support depends on the file and Android version.

Batch conversion

Select multiple files, choose one common output format, and let Fliq process them one at a time. One failed file does not have to stop the rest.

PDF tools

Render PDF pages to PNG, JPG or WebP. Extract selectable PDF text into DOCX. Scanned PDFs need OCR, which is not included.

Office to PDF

DOCX and PPTX can be converted locally using text-first extraction. Legacy Office and spreadsheet conversion requires a separately configured server.

Merge and rename

Merge multiple selected images into one PDF, or rename copies using Clean, snake_case, Date + name, or a custom name.

Privacy-minded

Listed local conversions run on the device. If you configure the optional conversion server, files sent for server conversion leave the device and are handled by that server.

Honest about conversion quality

Fliq prioritizes a small footprint and local processing, not full desktop-office fidelity. PDF-to-Word, DOCX-to-PDF and PPTX-to-PDF are text-first: original page layouts, images, charts, tables, fonts and animations may not be preserved. Always check the output before relying on it.
